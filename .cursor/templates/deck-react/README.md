# Proposal deck — React

Data-driven deck: edit `src/slides.js` only (content, in the P1 slide order from `.cursor/rules/proposal.mdc`).
Styling tokens live at the top of `src/deck.css` — copy them from the approved design direction.

```bash
npm install
npm run dev        # present at http://localhost:5173  (← → Space · F fullscreen · P print · swipe · #n deep links)
npm run build      # static output in dist/ — open dist/index.html or host anywhere
```

Print / PDF: press `P` (one slide per landscape page; enable "Background graphics").
